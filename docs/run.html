Test your model on Bench Press

Run any model behind an API key on the benchmark, with the same prompts, answer parser and output format as the paper and the command-line runner. Choose codes of ethics, prompting configurations and minimal pairs, and compare your model with the four models of the paper on the same items.

Your key stays in your browser. It is sent only to the provider you choose, directly from this page; it is not sent to this site or stored unless you tick “remember for this tab”. Every call is billed to your account. For large runs, or providers that block requests from web pages, use the command-line runner in this repository (python -m benchpress run).
